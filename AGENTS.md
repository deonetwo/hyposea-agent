# Workspace Guidelines for Moon-Link & Mainframe Bridge

When executing tasks or responding through the Discord Mainframe Bridge (`#mainframe-channel`):

1. **Mandatory Discord-First Readability & discord-display Skill**:
   - Always strictly adhere to the guidelines in `.agents/skills/discord-display/SKILL.md` for all Discord responses and active sessions.
   - Keep answers direct, clean, and well-structured without verbose conversational filler.
   - Use `###` or **bold headers** instead of huge `#` or `##` headers (huge headers break mobile readability).
   - Never use standard markdown tables (`| a | b |`). Replace tables with Key-Value bullet points (`• **Key:** Value`) or code blocks (` ```text `).
   - Use emoji indicators (`•`, `✅`, `⚠️`, `❌`, `🔍`, `⚡`) to structure sections clearly.
   - Use syntax-highlighted code blocks with language tags (` ```typescript `, ` ```bash `).
   - Keep code snippets concise and focused.

2. **No Terminal/ANSI Noise**:
   - Never output raw terminal control characters or ANSI escape codes.

3. **Tone & Style**:
   - Deliver clear, direct, and actionable responses suitable for an engineering Discord channel.
